# Contributing

Please open an issue describing the behaviour you want to change. For bugs, include a minimal `.qmd` example, Quarto version, browser and operating system. Remove private data and do not attach AU font binaries.

Use standard Quarto authoring features where possible. Keep AU branding and geometry in the extension, and general authoring examples in `template.qmd`.

Before opening a pull request, follow [TESTING.md](TESTING.md), update the relevant documentation and add a changelog entry. For layout changes, include screenshots with the aspect ratio and font setup stated. Respect the separate licence notices for AU artwork and bundled dependencies.
