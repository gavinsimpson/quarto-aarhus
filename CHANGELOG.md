## 0.1.0 — 2026-09-27

First public release of the AU Reveal.js format.

- AU palette selection, three aspect ratios, shared title/content margins and slide-local branding.
- Native Quarto columns, figure panels, quotations, mathematics, code and speaker notes.
- Title-slide authors with affiliations, emails and Font Awesome ORCID links; independent presenter footers.
- Section motifs and optional endings, with AU seal fallback when Peto is unavailable.
- Contrast-aware text and marks for theme colours and custom solid slide backgrounds.
- Optional author-supplied AU font embedding; no AU fonts distributed.
- Overflow diagnostics, portable installation tests and browser validation.
- GitHub Pages documentation with a live starter deck.
