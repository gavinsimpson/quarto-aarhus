# AU web fonts

AU Passata (eight styles) and AU Peto are redistributed with permission.
These fonts are not licensed under the extension's MIT software licence.
See [the asset notice](../NOTICE.md) for ownership and unofficial-project status.

The WOFF2 files were converted from the original AU TTF files using FontTools
4.66.0 and Brotli 1.2.0, without subsetting. All glyphs, character mappings,
font names and licence metadata are retained. The source and output SHA-256
hashes and sizes are recorded in manifest.json.

To regenerate from the original TTF files, use tools/build-fonts.py in the
repository. Conversion tools are only needed by maintainers, not deck authors.
